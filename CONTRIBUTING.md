# Contributing to LearnSpace

Thank you for your interest in improving this educational prototype.

## Contribution guidelines

1. Keep the program beginner-friendly and modular.
2. Use clear class, method, and variable names.
3. Validate user input and provide helpful error messages.
4. Do not add real student personal data to examples or commits.
5. Test changes by running `python main.py` and following the README checklist.
6. Describe the purpose of a change in your commit message.

## Development setup

Python 3.9+ is recommended. The project currently uses only the Python standard library.

## Reporting an issue

When reporting a problem, include the steps to reproduce it and the expected and actual behaviour. Do not include passwords or personal student information.
